# การ์ดแต่งงานออนไลน์

การ์ดแต่งงานแบบเว็บ เปิดบนมือถือได้ทั้ง iPhone และ Android มีประตูเปิด ม่านแหวก อนิเมชั่นตามการเลื่อน นับถอยหลัง แผนที่ กำหนดการ Dress code และให้แขกส่งคำอวยพรเข้า Google Sheet ได้ บ่าวสาวแก้ข้อความทั้งหมดเองได้ที่หน้า `/admin`

คู่มือนี้อธิบายวิธีเอาการ์ดไปทำให้คู่ใหม่ ใช้เวลาประมาณ 30–45 นาที

---

## การ์ดทำงานอย่างไร

```
แขกเปิดการ์ด (GitHub Pages)
   │  ดึงข้อความล่าสุด / ส่งคำอวยพร / ดึงคำอวยพรของคนอื่น
   ▼
Google Apps Script (Web app)  ──►  Google Sheet ของบ่าวสาว
   ▲                                 ├ แท็บแรก: คำอวยพร
   │  ล็อกอิน / บันทึกข้อความ          └ แท็บซ่อน card-data: ข้อความบนการ์ด
หน้า /admin ของบ่าวสาว
```

| ไฟล์ | หน้าที่ | ต้องแก้สำหรับคู่ใหม่ไหม |
|---|---|---|
| `src/data.json` | ข้อความเริ่มต้นทั้งหมดบนการ์ด | **แก้** |
| `assets/monogram.png` | โลโก้อักษรย่อบนประตู ซองจดหมาย และท้ายการ์ด | **เปลี่ยน** |
| `assets/ic-*.png` | ไอคอนกำหนดการ (พระ ขันหมาก บ่าวสาว อาหาร) | ใช้ต่อได้ หรือเปลี่ยนก็ได้ |
| `config.js` | ลิงก์ Apps Script ของคู่นั้น | **แก้** |
| `apps-script/Code.gs` | โค้ดหลังบ้านที่วางใน Google Sheet | แก้แค่รหัสเริ่มต้น |
| `index.html`, `admin/index.html`, `app.js`, `app.css` | ตัวการ์ด สร้างจาก `src/` อัตโนมัติ | ไม่ต้องแก้เอง |
| `src/app.js`, `src/app.css` | โค้ดและหน้าตาการ์ด | ไม่ต้องแก้ ยกเว้นอยากเปลี่ยนดีไซน์ |

## สิ่งที่ต้องเตรียม

- ข้อมูลงาน: ชื่อ-นามสกุลบ่าวสาวและชื่อเล่น ชื่อพ่อแม่ วันเวลา สถานที่ ลิงก์ Google Maps กำหนดการ และสีชุด
- โลโก้อักษรย่อเป็นไฟล์ **PNG พื้นใส** กว้างประมาณ 700–1000 px ตั้งชื่อไฟล์ว่า `monogram.png`
- บัญชี Google ของบ่าวสาว ใช้สร้าง Sheet และ Apps Script
- บัญชี GitHub ใช้เผยแพร่การ์ด
- (ไม่บังคับ) ติดตั้ง [Node.js](https://nodejs.org) ไว้สร้างการ์ดจาก `src/data.json`

## ขั้นตอน

### 1. คัดลอก repo ไปเป็นของคู่ใหม่

- ถ้า repo ต้นฉบับเปิด **Template repository** ไว้แล้ว (Settings → General → ติ๊ก Template repository): กด **Use this template → Create a new repository** แล้วตั้งชื่อ เช่น `ABWedding`
- ถ้าไม่ได้เปิดไว้: กด **Fork** หรือดาวน์โหลด ZIP แล้วอัปโหลดขึ้น repo ใหม่

ชื่อ repo จะเป็นส่วนหนึ่งของลิงก์การ์ด เช่น `https://<ชื่อบัญชี>.github.io/ABWedding/`

### 2. เปลี่ยนโลโก้

อัปโหลด `monogram.png` ของคู่ใหม่ทับไฟล์เดิมในโฟลเดอร์ `assets/` ถ้าอยากเปลี่ยนไอคอนกำหนดการ ให้ใช้ชื่อไฟล์เดิม (`ic-monk.png`, `ic-khanmak.png`, `ic-couple.png`, `ic-food.png`) เป็น PNG พื้นใส ขนาดประมาณ 200 px

### 3. ใส่ข้อมูลของคู่ใหม่

ข้อมูลอยู่ที่ `src/data.json` ทุกค่าแก้ทีหลังที่หน้า `/admin` ได้ แต่ควรแก้ที่นี่ด้วย เพราะ **ชื่อการ์ดตอนแชร์ลิงก์ใน LINE หรือ Facebook มาจากไฟล์นี้**

| ช่อง | ความหมาย | ตัวอย่าง |
|---|---|---|
| `title` | ชื่อการ์ด ใช้บนแท็บเบราว์เซอร์และตอนแชร์ลิงก์ | `Kanjanaporn & Nattapong` |
| `monogramText` | อักษรย่อบนตราประทับซองจดหมาย | `KN` |
| `nameLatin1`, `nameLatin2` | ชื่อภาษาอังกฤษบนหน้าแรก | `Kanjanaporn` |
| `nicknames` | ชื่อเล่นใต้ชื่อ | `มด & เต้` |
| `heroDate` | วันที่บนหน้าแรก | `09 · 01 · 2027` |
| `weddingAt` | วันเวลาเริ่มงาน ใช้นับถอยหลังและปฏิทิน ปี ค.ศ. เวลาไทย | `2027-01-09T07:09` |
| `calendarEnd` | เวลาจบงาน สำหรับปุ่มบันทึกลงปฏิทิน | `2027-01-09T14:00` |
| `brideParents`, `groomParents` | ชื่อพ่อแม่ ขึ้นบรรทัดใหม่ด้วย `\n` | `นายก\nนางข` |
| `brideName`, `brideNick`, `groomName`, `groomNick` | ชื่อเต็มและชื่อเล่นบ่าวสาว | |
| `dateThai`, `venueDate`, `venueTime` | วันเวลาที่แสดงเป็นข้อความ | `วันเสาร์ที่ 9 มกราคม พ.ศ. 2570` |
| `address` | ที่อยู่สถานที่จัดงาน | |
| `mapsUrl` | ลิงก์ Google Maps ใช้กับปุ่มเปิดแผนที่และสร้าง QR code | `https://maps.app.goo.gl/...` |
| `timeline` | กำหนดการ แต่ละข้อมี `icon` (`monk` / `khanmak` / `couple` / `food` / `none`), `time`, `text` | |
| `colors` | สีชุด Dress code เป็นรหัสสี ใส่ได้ไม่เกิน 9 สี | `"#a6e3a3"` |
| `wishPhrases` | ข้อความสำเร็จรูปให้แขกแตะเลือกตอนเขียนคำอวยพร | |
| `letterTo`, `letterText` | ข้อความบนจดหมายในซอง | `Dear Mod & Tae` |
| ช่องอื่น ๆ | ข้อความในแต่ละส่วนของการ์ด | |

ระวังเรื่องรูปแบบ JSON: ข้อความต้องอยู่ในเครื่องหมาย `"` และต้องมี `,` คั่นทุกช่อง

**สร้างการ์ดจากข้อมูล (ต้องมี Node.js):** เปิด Terminal ในโฟลเดอร์ repo แล้วรัน

```bash
node src/build.js .
```

คำสั่งนี้สร้าง `index.html`, `admin/index.html`, `app.js` และ `app.css` ใหม่ จากนั้น commit แล้ว push ขึ้น GitHub

**ถ้าไม่มี Node.js:** ข้ามการ build ได้ แก้ไฟล์ `index.html` บน GitHub แค่บรรทัด `<title>`, `og:title`, `og:description` และ `description` ให้เป็นชื่อคู่ใหม่ ข้อความที่เหลือแก้ที่หน้า `/admin` ในขั้นตอนที่ 7 การ์ดจะโหลดข้อความจาก Sheet มาแสดงก่อนแขกเปิดประตูทุกครั้ง

### 4. สร้าง Google Sheet และ Apps Script

1. ใช้บัญชี Google ของบ่าวสาวสร้าง Google Sheet ใหม่ เช่น `อวยพรงานแต่ง ABWedding` แท็บแรกเป็นที่เก็บคำอวยพร
2. เมนู **ส่วนขยาย → Apps Script** → ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `apps-script/Code.gs`
3. แก้รหัสเริ่มต้นของหน้า admin ที่บรรทัดบน ๆ

   ```js
   var DEFAULT_PASSWORD = '03061991';
   ```

   ใส่เป็นตัวเลขอะไรก็ได้ที่บ่าวสาวจำได้ แล้วกดบันทึก 💾
4. **Deploy → New deployment** → กดเฟือง ⚙️ เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. กด Deploy → Authorize ถ้าขึ้นว่า "Google hasn't verified this app" ให้กด **Advanced → Go to … (unsafe) → Allow** เพราะเป็นสคริปต์ของบ่าวสาวเอง
6. คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`

### 5. ใส่ลิงก์ Apps Script ใน `config.js`

บน GitHub เปิดไฟล์ `config.js` → กดไอคอนดินสอ ✏️ → วางลิงก์ระหว่าง `''`

```js
window.CARD_API = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

แล้วกด **Commit changes**

### 6. เปิด GitHub Pages

ใน repo ของคู่ใหม่: **Settings → Pages → Build and deployment**
- Source: **Deploy from a branch**
- Branch: **main** และโฟลเดอร์ **/ (root)** → Save

รอประมาณ 1–2 นาที การ์ดจะเปิดได้ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

### 7. ตั้งค่าที่หน้า admin และทดสอบ

1. เปิด `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/admin/` แล้วเข้าด้วยรหัสเริ่มต้นจากขั้นตอนที่ 4
2. ตรวจและแก้ข้อความทุกส่วน กด **ดูตัวอย่าง** เพื่อดูบนการ์ด แล้วกด **บันทึก**
3. **หลังบันทึกโดยมีวันแต่งงานอยู่ในช่อง รหัสจะเปลี่ยนเป็นวันแต่งงาน** เช่น `09012027` ใส่ได้ทั้งปี ค.ศ. และ พ.ศ. ถ้าลบวันแต่งงานออก รหัสจะกลับเป็นรหัสเริ่มต้น
4. เปิดการ์ดบนมือถือ ส่งคำอวยพรทดสอบ 1 ข้อความ แล้วเช็กว่ามีแถวใหม่ใน Sheet
5. ถ้าไม่อยากให้แขกเห็นข้อความทดสอบ ให้พิมพ์อะไรก็ได้ในคอลัมน์ **E** ของแถวนั้น

## เช็กลิสต์ก่อนส่งการ์ดให้แขก

- [ ] โลโก้ ชื่อ วันที่ และสถานที่เป็นของคู่ใหม่ทั้งหมด ไม่มีข้อความของคู่เดิมหลงเหลือ
- [ ] แชร์ลิงก์ใน LINE ให้ตัวเองดู ชื่อการ์ดที่ขึ้นตอนแชร์ต้องถูก
- [ ] ปุ่ม "เปิดแผนที่" และ QR code พาไปถูกที่
- [ ] ปุ่ม "บันทึกลงปฏิทิน" ได้วันเวลาถูกต้อง
- [ ] ส่งคำอวยพรแล้วขึ้นอนิเมชั่น "ได้รับคำอวยพรแล้ว" และมีแถวใหม่ใน Sheet
- [ ] หลังส่ง คำอวยพรของคนอื่นลอยขึ้นมาให้อ่าน
- [ ] ทดสอบบนทั้ง iPhone และ Android

## ดูแลระหว่างใช้งาน

- **ดูคำอวยพร:** เปิด Google Sheet แท็บแรก มีคอลัมน์ เวลา / ชื่อ / เกี่ยวข้องเป็น / คำอวยพร
- **ซ่อนคำอวยพรไม่เหมาะสม:** พิมพ์อะไรก็ได้ในคอลัมน์ E ของแถวนั้น ข้อความจะหายจากการ์ดภายใน 30 วินาที
- **แก้โค้ด Apps Script โดยลิงก์ไม่เปลี่ยน:** วางโค้ดใหม่ → **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** ถ้ากด New deployment จะได้ลิงก์ใหม่ และต้องแก้ `config.js` ตาม
- **ลืมรหัสหน้า admin:** รหัสคือวันแต่งงานที่บันทึกไว้ หรือดูรหัสเริ่มต้นใน `Code.gs` ถ้าใส่ผิด 8 ครั้ง ระบบจะพักไว้ 10 นาที

## ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| หน้า admin ขึ้นว่า "ยังไม่ได้ใส่ลิงก์ Apps Script" | ยังไม่ได้ใส่ลิงก์ใน `config.js` หรือเพิ่งแก้ ให้รอ 1–2 นาทีแล้วรีเฟรช |
| ใส่รหัสถูกแต่เข้าไม่ได้ | ถ้าเคยบันทึกวันแต่งงานไว้แล้ว รหัสคือวันแต่งงาน ไม่ใช่รหัสเริ่มต้น |
| ส่งคำอวยพรแล้วขึ้นว่าส่งไม่สำเร็จ | ตอน Deploy ต้องตั้ง Who has access เป็น **Anyone** และ `config.js` ต้องเป็นลิงก์ที่ลงท้ายด้วย `/exec` |
| แก้โค้ด Apps Script แล้วไม่มีผล | ต้อง Deploy เป็น New version ทุกครั้งที่แก้ |
| แชร์ลิงก์แล้วชื่อการ์ดเป็นของคู่เดิม | แก้ `title` ใน `src/data.json` แล้ว build ใหม่ (ขั้นตอนที่ 3) หรือแก้ `<title>` และ `og:` ใน `index.html` แอป LINE อาจจำพรีวิวเก่าไว้สักพัก |
| การ์ดยังแสดงข้อความเก่าบนมือถือ | เบราว์เซอร์จำไฟล์เก่าไว้ รีเฟรชหรือปิดแล้วเปิดใหม่ |

## ข้อควรรู้ด้านความปลอดภัย

- ลิงก์ Apps Script อยู่ในโค้ดของเว็บ คนที่รู้เรื่องเว็บจะเห็นลิงก์และส่งข้อความเข้า Sheet ได้เอง ถ้ามีข้อความขยะ ซ่อนหรือลบแถวนั้นใน Sheet
- รหัสผ่านที่เป็นวันแต่งงานเดาได้ไม่ยาก ระบบพักการล็อกอินหลังใส่ผิดหลายครั้งเพื่อกันการเดารัว ๆ แต่ไม่ควรใช้การ์ดนี้เก็บข้อมูลที่เป็นความลับ
- คำอวยพรที่แขกส่งมา แขกคนอื่นอ่านได้บนการ์ด ยกเว้นแถวที่ซ่อนด้วยคอลัมน์ E
- ไม่ควรใส่ลิงก์ Google Sheet ไว้ในการ์ด เพราะแขกจะเปิดดูชีตได้
